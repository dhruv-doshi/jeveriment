This audit covers the small official files that fit on the development Mac. It does not report benchmark model results. `configs/rag/small_source_hashes.json` pins the SHA-256 of each of the 26 files. `data/sources/small_source_manifest.json` stores each downloaded URL, byte count, and checksum; `runs/production_rag_v1/{mirage,qasper}/source_manifest.json` stores preparation hashes and counts. Downloads and runs are intentionally outside Git.

## Source terms and hosted passage use

- [MIRAGE's repository license](https://github.com/gzxiong/MIRAGE/blob/main/LICENSE) contains a public-domain notice for that repository; MIRAGE combines questions from several underlying datasets. The [MedRAG Textbooks card](https://huggingface.co/datasets/MedRAG/textbooks/blob/9c72838920a1323ffa867467d3f7aa7b36b0f994/README.md) identifies 18 medical textbooks but gives no explicit license for the textbook text. Hosted passage transmission for this corpus remains unverified.
- [QASPER's dataset card](https://huggingface.co/datasets/allenai/qasper) states CC BY 4.0. Paper text also originates from scientific papers, so attribution and any paper-specific terms still need attention for publication and hosted use.
- [HotpotQA's dataset and processed Wikipedia](https://hotpotqa.github.io/wiki-readme.html) are stated as CC BY-SA 4.0; preserve source attribution when sharing artifacts.
- [CLERC's dataset card](https://huggingface.co/datasets/jhu-clsp/CLERC/blob/main/README.md) says “README in progress” and gives no explicit dataset license. Its source terms and hosted passage use remain unverified.
- [KILT's repository](https://github.com/facebookresearch/KILT) says its code is MIT; the 2019 Wikipedia knowledge source contains Wikipedia content and needs its own attribution/terms review. The code license does not establish rights for the corpus.

All live provider preflights used synthetic text; no benchmark passage was sent to TypeSafe or OpenRouter during this audit.

## VM completion gate

Use a VM with a large attached volume; the three missing raw corpora total over 45 GB before extraction, SQLite/FTS indexes, dense vectors, and temporary files. Budget at least **250 GB free**, then check actual disk use before each index build. Download the exact CLERC passage collection at `ef042f8`; the official KILT 2019 knowledge source; and HotpotQA's official [intro-only 2017 Wikipedia archive](https://hotpotqa.github.io/wiki-readme.html) (1,553,565,403 bytes, MD5 `01edf64cd120ecc03a2745352779514c`). Convert the Hotpot archive into `hotpotqa/wiki.jsonl` with one article title and its **intro paragraph sentence array** per line. Verify sentence numbering against supporting facts, then run `rag prepare` for CLERC, HotpotQA, and KILT-FEVER. Preparation must reject missing gold IDs. Do not substitute the Hotpot development file's `context` or a different Wikipedia dump.

The full five-source join, large-corpus indexing cost, and source permission questions are still open. Do not describe the five-dataset experiment as source-validated until those checks pass on the VM.
